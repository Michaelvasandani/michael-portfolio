# Portfolio information architecture prototype

Throwaway prototype answering: how should resume-derived sections, additive Project Profiles, and the Recent Work Digest be organized within the GitHub Pages Minimal theme?

Three variants are switchable through `?variant=A`, `?variant=B`, and `?variant=C` or the floating review bar.

## Run

From the repository root:

```sh
python3 -m http.server 4173 --directory .scratch/agentic-portfolio/prototypes/portfolio-information-architecture
```

Then open <http://localhost:4173/?variant=A>.

This is disposable decision-making code, not production implementation.
